# 华为杯数学建模项目仓库

本仓库用于团队协作完成华为杯数学建模竞赛项目。

## 项目结构

```
.
├── data/          # 数据文件
├── code/          # 模型代码
├── paper/         # 论文资料与草稿
├── results/       # 实验结果
└── requirements.txt
```

## 协作规范

- main: 稳定提交版本
- dev: 开发分支
- feature-*: 个人任务分支

提交信息建议：

- feat: 新功能
- fix: 修复问题
- docs: 文档更新

## 环境配置

```bash
pip install -r requirements.txt
```
