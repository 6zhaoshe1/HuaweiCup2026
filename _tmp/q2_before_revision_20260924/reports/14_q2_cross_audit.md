## 2. Codex 独立方案

独立方案提出四层结构：

1. 在 B1 上以完整模型规模轨迹为独立单位，拟合经典律
   \(L=E+AN^{-\alpha}+BD^{-\beta}\)，使用留一规模和后段 Token 阻断验证。
2. 在 B7 上以 `(N,D)` 为分组单位，比较加性 Q、有效数据量、N 项幂次、可约损失乘子等候选；B6 只作嵌套训练集，绝不与 B7 重复计数。
3. A、B Loss 不直接拼接。问题一配比模型只产生 A 源内无量纲相对指数 \(R_A(\mathbf p)\)，B 源幅度 \(\eta_p\) 明确标为不可识别。
4. 用偏导、弹性和精确求根计算 Q 提升 0.1 的等效参数扩张，并把证据等级随结果传递给问题三。

## 3. 老师教程：采用与保留意见

教程位置：`老师教程_F题/问题二/01.png`–`18.png`。

| 教程做法 | 处理 | 原因与本轮验证 |
|---|---|---|
| 对数残差 + Huber 稳健拟合经典律 | 采用 | 与原始 Loss Huber 在相同诚实划分比较；对数 Huber 的两种主验证平均 RMSE 略低，故入选。 |
| 共享指数、来源特定的不可约项/尺度 | 采用为“源内仿射校准” | B2/B4/B5 的绝对 Loss 不能直接沿用 B1，但 B1 可约项的排序在 B4、B5 上仍强；这支持分层/相对形状传递。 |
| 质量乘在可约损失上 | 作为候选并入公平比较 | `(N,D)` 分组五折中线性乘子 RMSE=0.06283，优于加性、有效数据量和 N 项幂次。 |
| 质量幂次再加自由指数 | 未选 | 幂次模型多 1 个参数，分组五折 RMSE=0.06294，未优于线性乘子；折内指数约 0.95–1.00，线性已足够。 |
| 用 A 组相对配比作用构造无量纲乘子 | 条件采用 | A 组跨 1M/60M/1B 的相对排序稳定，但 A→B 的幅度没有共同实验锚点，故只开放情景参数。 |
| B1 近乎完美拟合作为强泛化证据 | 不采用 | B1 极可能按经典律构造或高度贴合该律；超小残差和窄 Bootstrap 区间只表示附件内一致性，不代表现实外推不确定性。 |
| B10 近乎完美外推作为验证 | 不采用 | B10 是估算数据，且与 B1 公式高度同构；近乎完美结果被标为循环一致性检查。 |

教程的轨迹图、候选模型柱状图、等 Loss 曲线、资源替代曲线等视觉结构较有效，本轮保留这些“图的任务”，但全部用本轮结果重新生成。

| 问题 | 证据 | 影响 |

## 5. 最终模型选择

本轮最终采用模块化广义律：

\[
R(N,D)=AN^{-\alpha}+BD^{-\beta},\qquad
\psi_Q(Q)=1+\kappa(1-Q),
\]

\[
\widehat L(N,D,Q,\mathbf p;\eta_p)
=E+R(N,D)\,\psi_Q(Q)\exp[-\eta_pR_A(\mathbf p)].
\]

- 可识别主模型：`η_p=0`，由 B1+B7 分模块识别。
- 配比模块：返回 `R_A(p)`；非零 `η_p` 只能作为问题三敏感性情景。
- 这不是把 A、B 两个回归式相加，而是传递“源内标准化相对效应”。

完整结果见 `reports/15_q2_modeling_report.md`，接口见 `results/q2_interface_to_q3.json`。
