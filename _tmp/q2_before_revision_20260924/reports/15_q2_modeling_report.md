# F 题问题二：广义标度律建模与实验报告

更新时间：2026-09-24

## 1. 结论先行

本轮没有把 A、B 两组绝对 Loss 强行拼接。可由现有数据识别的主模型为：

\[
\boxed{
\widehat L_B(N,D,Q)
=E+\left(AN^{-\alpha}+BD^{-\beta}\right)\left[1+\kappa(1-Q)\right]
}
\]

其中 N、D 分别以十亿参数和十亿 Token 为单位。正式估计为：

\[
E=1.689838,\quad A=0.353969,\quad \alpha=0.339985,
\quad B=1.240275,\quad \beta=0.279892,
\quad \kappa=0.477543.
\]

配比通过问题一的 17 域模型构造相对指数 \(R_A(\mathbf p)\)，条件化完整式写为：

\[
\widehat L(N,D,Q,\mathbf p;\eta_p)
=E+\left(AN^{-\alpha}+BD^{-\beta}\right)
\left[1+\kappa(1-Q)\right]\exp[-\eta_pR_A(\mathbf p)].
\]

但 B 组没有领域配比变化实验，A/B 也没有绝对 Loss 锚点，因此 **\(\eta_p\) 不可由现有数据识别**。问题三的主预测必须取 \(\eta_p=0\)，同时单独读取 \(R_A(\mathbf p)\)；非零 \(\eta_p\) 仅作敏感性情景，不得写成估计值。

## 2. 数据、独立单位与证据等级

全量读取来自只读 `F题.zip`。`results/q2_data_inventory.csv` 覆盖 B1–B12；模型实际使用如下：

| 数据 | 规模/性质 | 本轮用途 |
|---|---|---|
| B1 | 1,176 条真实 Pythia 检查点，8 条完整规模轨迹 | 经典 N–D 标度律主拟合；独立单位是模型规模轨迹，不是检查点。 |
| B2 | 1,029 条半合成 Cerebras 轨迹 | 来源迁移与“早期校准→后段预测”，不与 B1 绝对合并。 |
| B3 | 8×500 插值轨迹 | 与 B1 非独立，本轮不用于拟合或独立验证。 |
| B4 | 57 个真实收敛跨族点 | 检验 B1 可约项形状经目标源仿射校准后是否保留。 |
| B5 | 44 个文献点 | 同上；来源混合带来额外不确定性。 |
| B6 | 360 条半合成 N–D–Q | 是 B7 真子集；只作“B6 训练→B7 新增 Q 档”实验。 |
| B7 | 450 条半合成 N–D–Q | Q 候选模型的 `(N,D)` 分组五折主比较。 |
| B8 | 1,704 条半合成/外推 | 版本迁移压力测试；不参与选模。 |
| B9/B11/B12 | 真实元数据 | 描述模型、模型族和检查点，不含可直接拟合的 Loss。 |
| B10 | 128 条估算大模型 Loss | 循环一致性/外推敏感性，不作为独立证据。 |

重叠审计的两个决定性结果：

- B6 与 B7 重叠 360/360 条，Loss 全部一致；禁止联合计数。
- B7 与 B8 有 224 个相同 `(N,D,Q)` 键，但 224 条 Loss 全部不一致；B8 必须视作不同版本/机制，而不是更多独立重复实验。

证据文件：`results/q2_overlap_audit.csv`。

## 3. 经典标度律

### 3.1 模型与估计

基线为：

\[
L_0(N,D)=E+AN^{-\alpha}+BD^{-\beta}.
\]

比较两种相同结构、不同目标空间的稳健非线性拟合：原始 Loss Huber 和对数 Loss Huber。参数均施加正值和合理边界，多起点求解。

验证严格按相关结构切分：

- 留一模型规模：整条 N 轨迹留出；
- 后段 Token：每条轨迹最后 25% 的 D 留出；
- 随机检查点五折只作“泄漏乐观程度”诊断，不参与主结论。

### 3.2 结果

| 目标空间 | 留一规模 RMSE | 后段 Token RMSE | 留一规模 R² | 后段 R² |
|---|---:|---:|---:|---:|
| 原始 Loss Huber | 0.0001512 | 0.0001124 | 0.99999980 | 0.99999977 |
| 对数 Loss Huber | **0.0001501** | **0.0001117** | **0.99999981** | **0.99999977** |

对数 Huber 略优，故作为主估计。独立 `curve_fit` 复核的五个参数与主实现最大相对差为 `5.12e-5`。

这些异常小的误差说明 B1 与经典律高度一致，但不应被解释为现实跨架构预测几乎无误。按完整轨迹 Bootstrap 的 95% 区间也极窄：

| 参数 | 点估计 | 95% 分组 Bootstrap 区间 |
|---|---:|---:|
| E | 1.689838 | [1.689622, 1.689960] |
| A | 0.353969 | [0.353750, 0.354139] |
| α | 0.339985 | [0.339779, 0.340161] |
| B | 1.240275 | [1.240162, 1.240429] |
| β | 0.279892 | [0.279826, 0.279934] |

该区间只覆盖“B1 轨迹抽样不确定性”，不覆盖数据生成机制、tokenizer、架构和验证集变化。

### 3.3 跨源兼容性

B1 公式直接用于 B2 时 RMSE=1.243、R²=-5.073，证明绝对 Loss 不兼容。对 B1 的可约项

\[
R(N,D)=AN^{-\alpha}+BD^{-\beta}
\]

在目标源中只估计 \(L_s=E_s+s_sR\) 后：

- B4：RMSE 从 0.293 降至 0.103，R²=0.951，Spearman=0.983；
- B5：RMSE 从 0.198 降至 0.160，R²=0.824，Spearman=0.959；
- B2：全源仿射校准后 R²=0.447；用前 70% Token 校准、预测后 30% 时 Spearman=0.994，但 R²=-2.400。

因此可以传递“规模形状/排序”，不能传递未经校准的绝对 Loss。B2 后段的高排序、负 R² 也说明单一仿射校准仍有系统水平漂移。

B10 的未校准 R²=0.999992，不作为成功外推证据：它是估算数据，近乎完美更可能反映与经典公式同源。

## 4. 质量 Q 的作用形式

### 4.1 候选模型

在固定 B1 经典参数的基础上，比较：

1. 无 Q；
2. 加性修正 \(L=L_0+c(1-Q)\)；
3. 可约项线性乘子 \(L=E+R[1+\kappa(1-Q)]\)；
4. 可约项幂次乘子 \(L=E+R[1+\kappa(1-Q)^\gamma]\)；
5. 有效数据量 \(D_{eff}=D\exp[\kappa(Q-1)]\)；
6. DeepSeek 风格的 N 项 Q 幂次。

主评价为 B7 上按 `(N,D)` 分组的五折验证，使同一基础算力单元的不同 Q 档不会跨训练/验证泄漏。次评价为只用 B6 的 8 个 Q 档训练，在 B7 新增的 90 条 Q 记录上检验。

### 4.2 公平比较

| 模型 | `(N,D)` 分组五折 RMSE | 新增 Q 档 RMSE | 分组五折 R² |
|---|---:|---:|---:|
| 无 Q | 0.20731 | 0.16159 | 0.6296 |
| 加性 | 0.07396 | 0.06012 | 0.9529 |
| **可约项线性乘子** | **0.06283** | **0.04693** | **0.9660** |
| 可约项幂次乘子 | 0.06294 | 0.04729 | 0.9659 |
| 有效数据量 | 0.11761 | 0.07849 | 0.8808 |
| N 项 Q 幂次 | 0.10898 | 0.08271 | 0.8976 |

线性可约项乘子胜出。幂次模型多一个参数却没有改善验证误差，各折 \(\gamma\) 约为 0.95–1.00，所以保留更简洁的线性式。

质量系数 \(\kappa=0.477543\)，按 `(N,D)` 单元 Bootstrap 的 95% 区间为 `[0.448961, 0.509673]`。独立闭式 OLS 复核得到 0.459971，与稳健对数拟合相差 0.01757。

这仍然只是半合成 B7 内的结构识别。选定模型在 B8 calibrated 段 R²=-2.829、Spearman=0.020，在 extrapolated 段 R²=-3.236、Spearman=-0.127。结合 224 个同键不同 Loss，说明 B8 不是同一可直接迁移的 Q 机制，不能把 B7 的 \(\kappa\) 宣称为真实训练规律。

## 5. 配比 p 的模块化融合

问题一主模型对 17 域配比输出 13 个验证域 Loss。为避免不同验证域尺度支配，先把 13 个预测分别在 A4 上标准化，再取均值并反向，得到“越大越好”的相对指数 \(R_A(\mathbf p)\)。该指数在 A4 上中心化、标准化，不携带 A 组绝对 Loss 单位。

跨尺度验证：

| 数据 | \(R_A(p)\) 与更优观测 Loss 的 Spearman | A 源内描述性幅度 |
|---|---:|---:|
| 1M 训练 | 0.916 | 0.388 |
| 1M 留出 | 0.909 | 0.369 |
| 60M 留出 | 0.893 | 0.379 |
| 1B 留出 | 0.752 | 0.415 |

相对排序跨尺度保持较好，因此 \(R_A(p)\) 可以作为配比模块输出。A 源内幅度集中在 0.369–0.415，但它不能直接当作 B 源 \(\eta_p\)。完整接口中：

- 主预测：`η_p=0`；
- 配比排序：单独返回 `R_A(p)`；
- 问题三敏感性：可在明确标注“条件情景”的前提下测试 `η_p∈{0,0.25,0.5}`；
- 不得把非零情景写成数据估计或因果效应。

## 6. 边际效用、弹性与替代关系

记 \(g(Q)=1+\kappa(1-Q)\)，在 `η_p=0` 时：

\[
\frac{\partial L}{\partial N}
=-\alpha A N^{-\alpha-1}g(Q),\quad
\frac{\partial L}{\partial D}
=-\beta B D^{-\beta-1}g(Q),
\]

\[
\frac{\partial L}{\partial Q}
=-\kappa\left(AN^{-\alpha}+BD^{-\beta}\right).
\]

相对弹性统一定义为 \(\varepsilon_x=-x(\partial L/\partial x)/L\)。`results/q2_marginal_and_substitution.csv` 给出 36 个校准范围内情景的偏导与弹性。

对 Q 提升 \(\Delta Q=0.1\)，等 Loss 的精确参数规模 \(N'\) 满足：

\[
N'^{-\alpha}
=\frac{1}{A}\left[
\left(AN^{-\alpha}+BD^{-\beta}\right)
\frac{g(Q+0.1)}{g(Q)}-BD^{-\beta}
\right].
\]

右端不为正时不存在有限的等效 N。本轮在 `N∈{0.1,1,10}B`、`D∈{10,100,300}B`、`Q∈{0.3,0.5,0.7,0.9}` 的 36 个情景均存在解，等效参数倍率范围为 **1.154–2.149**，中位数 **1.290**。这直接否定“Q+0.1 恒等于固定百分比参数扩张”的说法：倍率取决于初始 N、D、Q。

结果中的区间只传播了 B7 的 Q 参数 Bootstrap；未覆盖 B1 结构误差、A/B 源差异和 Q 定义误差。

## 7. 固定算力下的 N–D 配置

当 \(C=6ND\) 且 N、D 使用绝对计数时，令 \(K=C/(6\times10^{18})\)（对应 N、D 的十亿单位乘积），有：

\[
N^*=\left(\frac{\alpha A}{\beta B}K^\beta\right)^{1/(\alpha+\beta)},
\qquad D^*=K/N^*.
\]

因此：

\[
N^*\propto C^{0.4515},\qquad D^*\propto C^{0.5485}.
\]

正式表 `results/q2_compute_optimal.csv` 只覆盖 B1 已观测算力范围。由于选中的 Q 和条件 p 因子共同乘在整个可约损失上，在固定 Q、p 时它们不改变 N:D 的内部最优比例；问题三若给 Q、p 赋予成本函数，最优解才会改变。

## 8. 失败实验与不可识别项

1. **有效数据量模型未胜出**：分组五折 RMSE=0.11761，明显高于 0.06283；不能因为解释漂亮就采用。
2. **Q 调 N 项未胜出**：RMSE=0.10898；DeepSeek 旧结论受 B6/B7 重复和样本内选模影响。
3. **自由 Q 幂指数无收益**：额外参数没有降低独立验证误差。
4. **B8 迁移失败**：同键数据定义冲突，不是简单扩大样本量即可解决。
5. **A→B 配比幅度不可识别**：只有相对排序证据，没有共同 tokenizer、验证集或联合 `(N,D,Q,p)` 实验。
6. **问题一 Q 与 B 组 Q 尚未完成真实标定**：当前将二者视作同向 `[0,1]` 尺度只是接口约定，不能宣称相同物理量。
7. **因果性未建立**：所有偏导和替代率都是模型内情景，不是现实干预效果。

## 9. 问题三接口

机器可读接口：`results/q2_interface_to_q3.json`。

输入约定：

- `N`：十亿参数；B1 校准范围 0.070542–11.965825。
- `D`：十亿 Token；B1 校准范围 0.134–299.893。
- `Q`：B7 半合成质量尺度，校准范围 0.1–1.0；问题一 Q 接入前必须保留标定警告。
- `p`：17 维非负向量且和为 1；由问题一模型转换为 `R_A(p)`。
- `eta_p`：默认 0；非零仅用于条件敏感性。

建议问题三不要直接调用一个“看似完整但含未识别参数”的黑箱。应调用三个并列输出：

1. `L_scale_quality(N,D,Q)`：已识别的 B 源主模型；
2. `R_A(p)`：已验证的 A 源相对配比指数；
3. `L_conditional(...,eta_p)`：明确标注情景参数的敏感性接口。
