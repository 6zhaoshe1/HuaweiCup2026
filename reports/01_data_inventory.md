# F 题实际数据清单与正式数据审计

## 1. 审计方法与总体结论

审计对象为只读 `F题.zip`，SHA-256 为 `368b78d5ff616983e567743036fc470481e4b97ba59ed995de8ea37d6d42b429`。`code/00_data_audit.py` 对全部 2,014 个文件条目计算 CRC、SHA-256 与字节数；41 个 CSV 全量解析；4 个 XZ/JSONL 共 410,539 条记录全量流式解析；C8 的 1,958 个 JSON 逐个解析。没有以抽样代替全量处理。

结论：**完整 `F题.zip` 中 A1–A18、B1–B12、C1–C10 全部存在。** 当前磁盘上旧 `F题/real_attachments/` 解压目录不完整，但本轮没有使用它作为完整来源，也没有覆盖原附件。

机器可读工件：

- `results/00_file_inventory.csv`：2,014 条文件级清单；
- `results/01_logical_attachment_status.csv`：A1–C10 逻辑编号状态；
- `results/02_tabular_profile.csv`：行列、字段、类型、缺失、唯一值、范围和重复；
- `results/03_c8_json_profile.csv`：1,958 个 C8 JSON 的逐文件状态；
- `results/04_overlap_checks.csv`：训练/检验、跨表和配比重叠检查；
- `code/outputs/00_data_audit.log`：完整运行记录。

### A 组关键质量问题

1. A1 的 22 个质量信号为 14 个标量和 8 个列表：`fluency_en`/`ad_en` 长度 2，`fineweb_edu` 长度 1，四类 ModernBERT 指标长度 6，`qurater` 长度 4。列表压缩规则属于模型选择，必须只在训练阶段冻结并解释标签语义。
2. 原始指标方向不统一。题面只明确“处理后统一越高越好”，没有提供全部 22 项的可靠方向表；逐指标方向属于**待队员核验假设**，不能从隐藏文字获取。
3. 配比行和约为 0.996–1.003，属于三位小数存储的舍入误差；正式建模可在记录原值后归一化到单纯形。不得把偏差直接解释成额外领域。
4. A6/A8 是同一 256 个配比在不同模型尺度上的 Loss；A12/A14 是同一 63 个训练配比的 10B/70B 外推。切分单位应是“配比向量”，不是表行或局部 index。
5. A1 与 A2/A3 存在 id 重叠。若进行样本级训练/验证，必须按 id 分组；若只做域级统计，也要避免将重叠记录重复加权。

## 5. 数据泄漏与重复使用结论

- A1–A2 重叠 1,419 个 id，A1–A3 重叠 10,000 个 id；A2–A3 无 id 重叠。
- A12/A14 的全部 63 个配比均来自 A4；A6/A8 是同一 256 配比的跨尺度成对实验。这些是设计结构，不应随机拆行。
- C1/C2/C9 是同一 Leaderboard 的不同版本；C5 是 C6 的 43 行子集；C1/C3 有 4,489 个规范化模型名重叠。训练、回测或 bootstrap 必须按规范化模型/模型族和时间分组。
- 同一 C8 模型目录最多两份评测文件；若选“最新记录”，该选择规则必须在看到结果前冻结。不能把同一模型的两次评测当独立模型。

## 6. 尚未通过的审计项

1. C9 因本机无 `pyarrow/fastparquet` 且镜像安装失败，尚未完成列级类型、缺失和重复核验；文件字节、CRC、SHA-256 已通过。由于题面允许 C1 或 C2，当前立项不被阻断。
2. 22 个质量指标的逐项方向、列表标签顺序和语义仍需依据可核验上游项目文档或队员人工确认；不能从隐藏 PDF 获取。
3. C4 的模型名与 C1/C3 连接率低，需设计规范化、别名和人工复核规则；未经复核不得把未匹配记录当“没有算力信息”。
4. 本轮只做审计，没有生成训练/验证索引。正式建模前应把分组规则写成机器可读索引并冻结。
