# F 题四问问题画像、硬约束与变量符号表

## 1. 任务简报

- 竞赛：2026 年“华为杯”第二十三届中国研究生数学建模竞赛；
- 赛题：F 题《算力约束下提升大语言模型能力的资源配置建模》；
- 用户：参赛队员；目标读者：竞赛评委；
- 正式主问题数：4；
- 当前范围：问题画像、数据契约和验证设计；不冻结核心模型，不进行正式参数寻优，不写论文终稿。

## 2. 统一变量与符号

| 符号 | 定义 | 单位/范围 | 来源与状态 |
|---|---|---|---|
| `N` | 模型参数量 | 实际参数个数；表中常用 B | B1–B12、C1/C4/C5/C6 |
| `D` | 训练 Token 数 | 实际 Token；表中常用 B | B1–B10 |
| `C` | 总训练/计算预算 | FLOPs | 题面；典型情景 `10^19,10^22,10^24` FLOPs |
| `L` | 验证集交叉熵 Loss | 无量纲，越低越好 | A4–A15、B、C5/C6 |
| `E` | 不可约损失 | 与 Loss 同尺度 | 待估计，禁止采用隐藏预填值 |
| `Q` | 统一方向后的数据质量评分 | 建议限定 `(0,1]` 或标准化尺度 | 问一输出；定义待队员确认 |
| `p` | 17 域配比向量 | `p_i≥0, Σp_i=1` | A4/A6/A8/A10/A12/A14 |
| `L_ctx` | 上下文长度 | Token；2,048–131,072 为 C7 当前范围 | 外生变量，不得内点寻优 |
| `C_train` | 基础训练成本 | `6ND` FLOPs | 题面硬定义 |
| `C_Q` | 质量提升成本 | `D[g(Q)-g(Q0)]_+` | 题面；`g` 三类候选及参数见附录 B |
| `C_attn` | 长文本注意力代理成本 | `ηNDL_ctx`，`η=2×10^-4` | 题面硬定义 |
| `L_ctx^crit` | 注意力成本与训练成本相当的临界长度 | `6/η` | 题面要求解析给出并在 C7 可行域检查 |
| `S` | Benchmark 综合能力 | 通常 0–100 或自定义透明聚合 | C1/C2/C3/C8；定义待冻结 |
| `t` | 模型时间轴 | 提交日/发布日期/版本日期三选一 | 问四必须说明口径 |

单位换算：B 表中的 `N_params_B`、`D_tokens_B` 以 `10^9` 为单位；`C_FLOPs_1e21` 以 `10^21 FLOPs` 为单位。任何公式计算前必须恢复一致单位。

## 3. 问题一画像

| 项目 | 冻结内容 |
|---|---|
| 任务目标 | 构造可解释的质量分 `Q`；定义质量冲突并消解；建立 17 域配比 `p` 与 13 域 Loss 的关系 |
| 变量 | 22 个质量指标、文本/来源域、`Q`、冲突分数、17 维 `p`、13 维/聚合 Loss、模型尺度 |
| 数据 | A1–A3 全量质量信号；A4–A15 配比与 Loss；A16 映射；A18 可选文本核验 |
| 硬约束 | 全量使用 A1–A3；指标处理后越高越好；`p_i≥0,Σp_i=1`；A6–A11 检验；A12–A15 外推稳健性 |
| 独立数据单位 | 质量层为唯一文本 id；配比层为唯一 17 维配比向量；同配比跨尺度为重复测量 |
| 评价真值 | 质量评分无直接统一真值，需用内容/域一致性和下游 Loss 支持；配比模型真值为冻结检验表 Loss |
| 不确定性 | 指标方向/列表语义、域映射、主观聚合、跨尺度结构、Loss 汇总方式 |
| 待定假设 | 22 指标方向表；列表压缩；冲突阈值；A16 是否直接采用；13 域 Loss 的主评价聚合 |
| 验收标准 | 无未来/检验泄漏；A6–A11 相对透明基线有稳定样本外表现；跨 1M/60M/1B 结论方向可解释；A12–A15 只作外推证据 |

特别记录：A1 与 A2/A3 有 id 重叠，A12/A14 是 A4 子集，A6/A8 是相同配比的尺度配对。随机逐行切分不合格。

## 4. 问题二画像

| 项目 | 冻结内容 |
|---|---|
| 任务目标 | 将 `N,D,Q,p` 纳入广义标度律，估计边际效用/弹性，讨论质量与规模及不同领域的替代或互补 |
| 变量 | `L,E,N,D,Q,p`、模型族、run、checkpoint、数据性质/可比性 |
| 数据 | 问一输出 `Q,p`；B1 主拟合；B2 或 B3 轨迹/族外验证；B4/B5 跨族/文献验证；B6–B8 质量补充；B9/B10 大规模外推 |
| 硬约束 | A、B 来源独立；B6–B8 标为半合成，B10 标为估算；若宣称 `Q=1` 退化到经典形式须说明依据；必须参数估计、检验和验证 |
| 独立数据单位 | 模型训练 run/模型族；同一 run 的检查点不是独立样本 |
| 评价真值 | 冻结验证 run/族的交叉熵 Loss；不同验证集 Loss 不能默认完全可比 |
| 不确定性 | Loss 口径、Q 标度、p 高维识别、模型族随机效应、外推函数形式、半合成生成机制 |
| 待定假设 | 广义函数形式；A/B 统一的校准项；p 的降维/正则化方式；质量与规模交互项是否可识别 |
| 验收标准 | 相对经典幂律的族外/轨迹验证增益；残差结构无明显规模段失配；参数符号/弹性在重采样中稳定；外推区间覆盖已知大模型基准 |

## 5. 问题三画像

| 项目 | 冻结内容 |
|---|---|
| 任务目标 | 在算力约束下联合配置 `N,D,Q,p`，比较质量成本函数并识别预算跨量级时的结构性转移 |
| 变量 | 决策 `N,D,Q,p`；外生 `C,L_ctx,Q0,η`；输出 Loss、三类成本、约束残差、转移点 |
| 数据 | 问一/二的冻结接口；C7 给 `L_ctx` 可行范围；题面附录 B 给质量成本函数 |
| 硬约束 | `C_train+C_Q+C_attn≤C`；`N,D>0`；`Q∈(0,1]`；`p` 单纯形；`L_ctx` 外生；至少三个预算量级；解析给出 `L_ctx^crit=6/η` |
| 独立数据单位 | 一个预算×成本函数×上下文长度情景；优化解不是统计独立样本 |
| 评价真值 | 可行性残差、目标独立复算、基线策略对比；没有现实干预真值 |
| 不确定性 | 上游参数、质量成本形式、上下文代理误差、边界范围、局部/全局最优性 |
| 待定假设 | `p` 联立还是由前问冻结；`N,D,Q` 可行上下界；预算档位除题面建议外是否扩展；转移定义 |
| 验收标准 | 所有硬约束满足；先有可行解再比较目标；报告最优间隙或全局性边界；三类 `g(Q)` 与上游参数区间下结论不翻转或明确翻转区间 |

结构性转移必须预定义，例如最优解从一个活跃约束/边界组合切换到另一个组合，或资源份额出现超过预设阈值且跨不确定区间保持。不得事后看图定义转移。

## 6. 问题四画像

| 项目 | 冻结内容 |
|---|---|
| 任务目标 | 分解规模扩张与非规模技术进步的贡献；在算力增长放缓情景下预测未来 12/24 个月开源模型前沿并量化不确定性 |
| 变量 | Benchmark 各维、综合能力 `S`、`N,D,C,t`、模型类型、开源权重/许可证、架构、Loss 与桥接误差 |
| 数据 | C1 或 C2、C3、C4 必用；C8 至少一项逐任务聚合；C5/C6 桥接；C7 架构辅助 |
| 硬约束 | 明确开源筛选、pretrained/chat 区分、时间口径；桥接按可比性等级；预测含不确定性；不得把时间残差直接称因果技术进步 |
| 独立数据单位 | 规范化模型/模型版本；同模型重复评测和同族衍生模型需分组；时间回测以历史截点为单位 |
| 评价真值 | 历史滚动截点后的真实前沿和 Benchmark；未来 12/24 月目前无真值，只能情景预测 |
| 不确定性 | 模型名连接、缺失算力、榜单选择偏差、许可信息缺失、桥接误差、前沿定义、时间外推、混杂 |
| 待定假设 | 综合能力聚合；前沿分位/包络；技术进步的观测定义；开放性规则；重复模型选择；算力放缓情景 |
| 验收标准 | 至少两个历史起点回测；与朴素前沿/趋势基线比较；按模型族阻断；桥接误差传播；区间覆盖和失败年份公开；贡献只作观测分解或明确识别假设 |
