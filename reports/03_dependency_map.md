# F 题四问依赖关系与跨问题接口

## 1. 依赖主链

```text
A1–A3 ──> Q、冲突与域级质量 ─┐
A4–A16 ─> p→Loss 关系 ───────┼─> 问二广义标度律及参数不确定性
B1–B12 ──────────────────────┘                 │
                                               ├─> 问三可行资源配置与情景结果
C7 ───────────────────────────────────────────┘

C1/C2+C3+C4+C8 ─> 历史能力与规模/时间面板 ─────┐
C5/C6 <─ 问二Loss规律 ─> Benchmark桥接 ────────┼─> 问四观测分解、回测与前沿情景
问三情景结果（仅在接口兼容时）─────────────────┘
```

问题四不必强行使用问题三的“最优解”。只有当问题三的 `N,D,C` 定义、模型类型、时间口径和问题四历史数据可匹配时，问题三情景才可作为未来算力约束场景；否则仅使用问题二的 Loss 规律和 C 数据。

## 2. 接口表

| 接口 | 上游输出 | 单位/范围 | 下游用途 | 放行条件 |
|---|---|---|---|---|
| Q1→Q2/I1 | `Q_definition`、方向表、预处理与域聚合 | `(0,1]` 或冻结标准化尺度 | 广义标度律质量项 | A1–A3 全量；方向和列表压缩有来源；无 id 泄漏 |
| Q1→Q2/I2 | `p_loss_model`、17域顺序、13域 Loss 聚合 | `p∈Δ^16` | p 主效应/交互项 | A6–A11 验证通过；尺度配对口径明确 |
| Q2→Q3/I3 | 广义 Loss 函数、参数估计、协方差/重采样样本 | Loss | 优化目标与参数情景 | 族外/轨迹验证通过；外推域被声明 |
| Q1→Q3/I4 | `Q0`、质量可行范围、p 可行域 | `Q∈(0,1]`、`p∈Δ^16` | 成本与决策边界 | Q 尺度有实际含义；边界不是从最优解反推 |
| C7→Q3/I5 | `L_ctx` 可行集合、架构字段 | Token | 外生情景与敏感性 | 匹配规则和模型名核验 |
| Q2→Q4/I6 | Loss 预测和外推区间 | Loss | C5/C6 桥接 | Loss 定义与桥接来源可比；High/Medium 分层 |
| Q1/Q2/Q3→Q4/I7 | 规模、质量、配比与算力情景 | 统一单位 | 解释性情景 | 不把优化情景当历史观测或因果证据 |

正式实现时，每个接口至少保存：schema 版本、字段顺序、单位、来源文件 SHA-256、适用域、随机种子、训练/验证索引、参数与不确定性、生成脚本和时间戳。

## 3. 可合并性判断

- A4–A15 内部可按 `index` 成对连接，但跨表的相同 index 只是局部编号；必须使用 17 维配比向量判断重复。
- A 与 B 实验独立，只能通过可检验的 Loss 规律、`Q` 和 `p` 接口融合；不能直接纵向拼表后当同分布样本。
- B1 与 B2/B3 可用于主拟合—外部/轨迹验证，但同一模型 run 的检查点应分组。
- C1、C2、C9 只能三选一作为 Leaderboard 主表，不能堆叠。
- C3 含 26 条历史来源记录和 4,573 条榜单记录，应保留 `Source` 分层。
- C4 与榜单模型名需要别名/规范化；低连接率不得静默丢弃。
- C5/C6 的 Loss 来自不同验证集，只能在可比性分层/层级模型或敏感性假设下连接 Benchmark。

## 4. 误差传播与回退

| 上游失败 | 影响 | 必须回退检查 |
|---|---|---|
| Q 方向/列表压缩不稳定 | 问二质量弹性、问三质量配置失效 | 方向表、标签语义、稳健标准化、域聚合 |
| p→Loss 在 A6–A11 无增益 | 问二 p 项和问三联立 p 不放行 | Loss 聚合、单纯形变换、交互复杂度、尺度层级 |
| 广义律族外失效 | 问三目标和问四 Loss 外推失效 | A/B 口径、模型族效应、参数可识别性、外推域 |
| C5/C6 桥接不稳定 | 前三问无法可靠映射到 Benchmark | High 子集、来源分层、单调/非线性形式、误差区间 |
| 模型名/时间/开源口径不稳 | 问四贡献与前沿结论降级 | 别名表、时间字段、许可证和模型类型人工复核 |
| 优化只得到局部/边界敏感解 | 问三仅能报模型内候选 | 可行域、尺度化、多起点/全局界、上游参数情景 |

上游接口发生定义变化时，所有依赖结果作废并从最早受影响环节重跑，不能只修改文字解释。

## 5. 问题一独立版本的已实现接口（2026-09-23）

- Q1→Q2 不传未经独立验证的绝对标量 Q；传递四分面、域级区间、冲突/异常标志和源内相对尺度。题目要求的统一 Q 仅标记为 `definition_based_relative_score`。
- 配比接口采用 17 域 ILR-Ridge；在 1M 同尺度独立检验有效。60M/1B 的排序仍较稳定，但绝对 Loss 水平偏移，故只传源内标准化效应与排序，不传可直接跨尺度使用的绝对 Loss。
- A、B 保持完全独立；没有共同锚点前不得拟合绝对 Loss 映射或纵向拼表。
- Qmix 仅覆盖 6 个直接/近直接映射域，并且是配比的确定函数，不能作为独立质量处理效应。
- 机器可读契约、适用域、禁止主张和证据路径集中保存在 `results/q1_interface_to_q2.json`。
