## 2. 质量评分基线

### 2.1 指标变换

- 六分类 ModernBERT 指标使用未校准的期望等级
  \[
  e(\mathbf z)=\sum_{k=0}^{5} k\,\frac{\exp(z_k-\max\mathbf z)}{\sum_j\exp(z_j-\max\mathbf z)}.
  \]
  `argmax` 只作可能的人工对照，不进入主评分。
- 二分类 `fluency_en`、`ad_en` 使用方向已冻结的 logit margin；这些值不是概率。
- QURATER 的四个位置分别保留，不作 `argmax`。
- 所有可进入质量评分的连续信号，用 A1 全体记录拟合经验分布函数，再将同一变换不变地应用于 A2/A3，避免扩展集反向改变参考尺度。
- RPS 单调类在“领域 × A1 长度五分位带”内作经验分位数变换；`top_2gram/top_3gram` 反向；数值字符、非字母、全大写比例按域内典型性处理；文长、句数、平均词长只用于结构异常，不进入 Q。
- DSIR 是目标域相似度，不进入通用 Q。直接除以词数后与对数长度仍高度相关，因此主口径进一步在域内对 `ln(word_count)` 回归取残差。

完整字段—变换—角色表为 `results/q1_indicator_transform_manifest.csv`。

### 2.2 四分面与统一相对分

分面由实际语义和字段相关性组成：

- 内容价值：FineWeb-Edu、QURATER facts、QURATER education；
- 语言质量：fluency、readability、QURATER style，以及温和正向 RPS；
- 清洁度：cleanliness、无广告 margin，以及域条件/重复 RPS；
- 推理专业：reasoning、professionalism、QURATER expertise。

每个分面同时计算等权均值和逐样本 Huber 稳健均值。若某分面标准化指标为 \(s_{ij}\)，稳健权重为
\[
w_{ij}=\min\left(1,\frac{1.5}{|s_{ij}-m_i|/(1.4826\,\mathrm{MAD}_i)}\right),
\quad F_i=\frac{\sum_j w_{ij}s_{ij}}{\sum_j w_{ij}}.
\]
题目要求的统一分数定义为四分面等权平均：
\[
Q_i^{\mathrm{def}}=\frac{F_{i,\mathrm{content}}+F_{i,\mathrm{language}}+F_{i,\mathrm{clean}}+F_{i,\mathrm{reason}}}{4}\in[0,1].
\]

该 Q 是透明的“定义性相对评分”，不是由独立人工标签识别出的真实质量，也不是可直接代入标度律的物理量。问二需要利用 B6–B8 在避免循环验证的前提下另行标定标量 Q；问一向后传递四分面、域级区间与敏感性，而不是把此处 Q 当成真实处理效应。

## 3. 冲突定义与消解

先计算语义指标家族分数 \(S_i\) 与形态统计家族分数 \(M_i\)，令 \(g_i=S_i-M_i\)。在 A1 的同域、同长度带内以中位数和 MAD 标准化：
\[
z_i=\frac{|g_i-\operatorname{median}(g\mid d,b)|}{1.4826\operatorname{MAD}(g\mid d,b)},
\qquad
C_i=0.5|g_i|+0.5\min(z_i/6,1).
\]
主阈值冻结为 A1 的 97.5% 分位数，同时报告 95% 与 99% 敏感性。Pareto 非支配关系只作四分面展示，不代替冲突定义。

测量异常独立定义：任一语义字段非有限，或文长、句数、平均词长的域内稳健标准分数超过 6。语义冲突不自动删除；只有存在测量异常证据时，Huber 聚合才降低极端指标权重。验证不能用“更平滑”代替真值，必须结合 A1 分层原文审查；已生成 84 条样本，人工标签目前故意留空。

## 4. 配比—Loss 基线

令 \(\mathbf p_r\in\Delta^{16}\) 为第 r 个 17 域配方。对零分量作乘法替换：若一行有 k 个零，每个零改为 \(\delta\)，正分量按比例缩放到 \(1-k\delta\)。再用 17 维 Helmert 正交基 \(H\) 得到
\[
\mathbf x_r=H\log(\widetilde{\mathbf p}_r)\in\mathbb R^{16}.
\]
13 个 Loss 共同使用多输出 Ridge：
\[
\widehat{\mathbf L}_r=\mathbf b+B\mathbf x_r,
\quad
\widehat B=\arg\min_B\sum_r\|\mathbf L_r-\mathbf b-B\mathbf x_r\|_2^2+\alpha\|B\|_F^2.
\]

训练数据内部使用固定种子 42 的五折划分；所有标准化仅在折内拟合。线性 ILR 是透明基线。后续实验暴露出两个不同缺陷：其预测 RMSE 明显弱于对数平移模型，且线性形式不能回答题面要求的组合效应。因此活跃方案冻结为不对称双模型：对数平移 Ridge 负责主预测，二次 ILR-Ridge 负责组成结构和组合情景；二者必须在同一闭合替代规则下做一致性校验。逐验证域单独选 alpha 的 ILR 改善低于0.1%，已从活跃候选中删除。

## 5. 验证、消融与跨尺度协议

- 主评价：逐验证域及宏平均的 MAE、RMSE、R²、Spearman、预测偏差；区分绝对 Loss 与配方排序。
- 真检验：A6/A7（1M）、A8/A9（60M）、A10/A11（1B）。A12/A13 与 A14/A15 是估算 Loss，只能标记 `extrapolated`。
- 质量消融：在相同 ILR、划分和指标下，只增加“可靠映射质量覆盖率”和“映射部分的加权平均质量”。因两者完全由配比决定，只能检验预测增益，不能识别独立质量因果效应。
- 跨尺度修正只设一个预先定义的诊断基线：用 1M 与 60M 的同配方差异估计逐域 `log(N)` 斜率，在 1B 检验；不得反复使用 1B 调公式。
- 1B 按完整配方记录进行 1,000 次 Bootstrap。
- 领域作用以“某域增加 1 个百分点、其他域按既定比例缩减”的闭合替代情景计算，并另做初始占比带、单一 donor 和双域联合情景。全部标记为 `model_scenario`，禁止解释为因果干预。

## 6. 失败判据与回退

1. Q 无独立标签：只能称相对定义分；队员未完成人工审查前不得称“最优质量分”。
2. Qmix 若只在部分尺度小幅改善或映射覆盖不足：不放行“质量有独立作用”的主张。
3. 同尺度排序好但跨尺度绝对 R² 为负：保留配方排序接口，绝对 Loss 交由问二重新建模。
4. A/B Loss 缺乏共同锚点：禁止纵向拼接，只传源内标准化效应和排序。
5. 外推估算表不得用来调参或作为独立真实验证。

## 9. 问题二广义标度律设计（2026-09-24）

问题二采用模块化而非 A/B 绝对 Loss 拼接：B1 识别经典规模项，B7 识别半合成质量项，A 组问题一模型只传递无量纲相对配比指数。主式为

\[
L_B(N,D,Q)=E+[AN^{-\alpha}+BD^{-\beta}][1+\kappa(1-Q)].
\]

条件配比接口为

\[
L(N,D,Q,\mathbf p;\eta_p)=E+[AN^{-\alpha}+BD^{-\beta}][1+\kappa(1-Q)]e^{-\eta_pR_A(\mathbf p)}.
\]

其中 `η_p` 在现有数据中不可识别，主预测固定为 0，非零值只作问题三敏感性。修订后的 `main` 模式拒绝 p 和非零 eta，`p_scenario` 模式要求显式假设与单纯形校验。Q1 综合质量分不能直接映射成 B7_Q_score。

经典律按完整 N 轨迹留一作为主验证，后段 Token 阻断作为次验证；修订 Q 模型为外五内四折 `(N,D)` 分组嵌套验证，包含六候选选择。B6 是 B7 真子集，禁止重复计数；B8 与 B7 同键 Loss 冲突，只作版本压力测试；B10 只作估算一致性。所有修订为看过旧结果后的公开变更，不称新的盲测。

新增 B4 留族、B5 留来源/留族；B4 同时剔除与 B1 共有的 Pythia 做敏感性。Bootstrap 与正式 Huber 估计器一致，并条件重拟合 Q；假定两组抽样扰动独立，不覆盖未知生成相关性。等效 N 采用解析可达性判别，优化基准须同时检查 N/D 支持，不以预算范围替代支持域。

模型选择与失败判据、三路交叉审计、完整公式见 `reports/14_q2_cross_audit.md` 和 `reports/15_q2_modeling_report.md`。

## 10. 问题三资源配置设计（2026-09-25）

问题三没有把四变量直接交给黑箱优化器。令十亿单位下 `c=C/1e18`、`h=6+eta*Lctx`、`s=[g(Q)-g(Q0)]_+/1e9`，预算约束化为 `D_B(hN_B+s)<=c`。由于冻结的广义标度律对 D 单调下降，在 D 未触及上界时可取预算等号并解析消去 D，主优化只需在 `(log N,Q)` 上进行。

主证据域严格取 B1 与 B7 支持交集；B9 只作有限外推护栏。上下文长度是 C7 给出的外生情景，没有能力收益项，不能作为内层决策。领域配比以 A4 历史配方的 `R_A(p)` 排序传递，主模型固定 `eta_p=0`；非零幅度只作条件敏感性，因为现有 A/B 数据没有识别它。

验证协议包括：三种题给质量成本、三档官方预算、C7五种上下文、支持域可行性、活跃集持续转移、差分进化对照、问题二300组联合重拟合逐次优化、90% Loss分位稳健候选、后悔评估，以及不导入主优化函数的独立公式/网格复算。不可行时保留缺口，高预算撞支持边界时另列外推，不通过放松约束获得漂亮解。

针对Q封顶，新增剖面函数 `phi(Q)=min_{N,D}L` 的单侧导数，将固定N/D的质量边际收益与预算约束造成的资源挤占代价分开；分别识别内点平衡、Q0处不投资、Q上界仍有净收益和N/D/Q支持上界导致的退化。固定Q时内层N分段的一阶条件比值严格单调，可证明每个分段至多一个驻点；外层Q未证明整体凸或单峰，故只声明多路线一致的数值最优。

支持域不再只报告边际范围。代码核实B1为8×147完整N-D笛卡尔设计，B7为9×5×10完整N-D-Q半合成因子设计，并对每个资源方案记录是否精确命中、网格凸包内插、到最近观测点的归一化距离、支持边界和理论外推等级。

完整设计、外部方案取舍和公式见 `reports/18_q3_independent_design.md`、`reports/19_q3_cross_audit.md` 与 `reports/20_q3_modeling_report.md`。

## 11. 问题四技术演进与累计前沿设计（2026-09-25）

问题四分开建模“新模型条件能力分布”和“截至时点累计最高能力”。六项 Benchmark 等权平均与官方 Average 在4492条记录上完全一致；条件分布在 logit 尺度拟合90%分位，累计前沿定义为 `F(t)=max_{Ti<=t} S_i`。

严格开源主口径要求 Hub 可用、未标记、SHA非空和许可证白名单；宽口径仅作敏感性。实体按 SHA 去重并固定保留最早提交，基础模型家族等权。pretrained/continually pretrained 与 chat/finetuned 分层，merges/domain fine-tuned 作为衍生层，不允许重复模型支配时间趋势。

条件分位候选统一做7折滚动时间回测。含时间候选只有在家族等权 Pinball 损失相对最佳纯规模模型改善至少5%时才启用；严格核心合并层未过门，因此主模型保留二次规模分位回归。Hub上传日只作时间轴敏感性，静态正系数不能替代时间回测。

C8恢复39项逐任务结果，控制规模、模型层与评测签名，标准误按基础模型家族聚类并做BH多重检验。规模与时间代理采用端点两因素Shapley分解并显式保留未解释残差；条件时间项称“非规模进步代理”，不作因果技术贡献解释。

累计前沿以持久性为基准，候选随机纪录过程同时模拟未来模型到达数、家族平衡规模分布、C4算力情景和经验残差；正式评价使用含真实纪录更新的9个截止日×30/60日滚动回测。12/24个月结果全部标记为条件情景外推，并交叉改变算力增长与未来模型到达率。

Loss–Benchmark 只在High可比性7点上做留一验证。综合能力桥接若不能超过常数基准即判不可识别；局部维度映射不得升级为统一桥接，前三问Loss不承担问题四主预测。
